# Syed Muhammad Ali Naqvi — Interactive 3D Portfolio

A cinematic, space-themed personal portfolio built as an interactive 3D digital environment.

## What this site represents

This portfolio is designed as a digital representation of my professional work, academic foundation, projects, skills, experience, and contact information — presented through an explorable 3D space rather than a conventional static portfolio layout.

### Featured work

- **AutiSmart** — Final Year Project focused on AI-assisted autism screening and support. FYP-I: **A+**; FYP-II: **A-**. Developed, deployed, and presented as part of the final-year project team.
- **ClinicOS** — Healthcare operations and workflow platform.
- **SchoolIEP** — Education-focused IEP records and workflow system.
- **EduCore** — Open learning hub with 400+ curated technical resources.

## Technology

Next.js · React · TypeScript · Three.js · React Three Fiber · Drei · CSS · Git/GitHub

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production

The `main` branch is connected to the deployed portfolio. Changes merged to `main` are automatically deployed through the project's deployment pipeline.

## Notes

The 3D experience is intentionally built around readability and usability: the space, camera movement, lighting, objects, and navigation support the portfolio content instead of replacing it.

This repository contains the portfolio implementation. It does not contain private credentials or deployment secrets.
